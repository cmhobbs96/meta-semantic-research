# scripts/

Core logic for training, evaluation, enhancement, and I/O.

## Key Subfolders
- `core/` – train.py, test.py, eval.py
- `util/` – constants, paths, logging, saving
- `dataset/` – COGSDataset and loading helpers
- `metrics/` – metric formulas and visualizations
- `enhancements/` – srl.py, kga.py, srt.py, rbm.py
