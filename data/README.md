# data/

This directory contains the COGS dataset in various enhancement formats.

## Subfolders
- `raw/` – Original unmodified COGS dataset (train/dev/test/gen)
- `srl/` – SRL-enhanced dataset with extracted semantic roles
- `kga/` – Knowledge graph augmented dataset
- `rbm/` – Rule-based cleaned dataset (optional)
- `srt/` – Dataset formatted for semantic role training
- `final/` – Combined enhancements used in the final evaluation

## Files
Each subfolder contains `train.tsv` with appropriate enhancements.
